System prompt and parameters (optional)
Same values go to every model. Some models clamp or ignore them.
Pick 2 to 4 models, enter a prompt and press Compare.
Prompts are sent to DigitalOcean serverless inference to get answers. This app does not store them; server logs keep only model names, timings, token counts and status. Costs are estimates from a price table dated -. Token counts come from each model's own tokenizer, so they are not directly comparable. One run is one sample: outputs vary, so use Run again.
